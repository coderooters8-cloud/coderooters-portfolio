CODEROOTERS — Premium Portfolio Website

FILES
- index.html: page structure and content
- style.css: responsive styling, layout, animation and visual effects
- script.js: scroll reveals, mobile menu, progress bar, back-to-top and dynamic year
- assets/coderooters-logo.png: your supplied CODEROOTERS logo

HOW TO RUN
1. Extract the ZIP file.
2. Open the coderooters-portfolio folder in VS Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.

CUSTOMIZE BEFORE PUBLISHING
- Replace the concept projects in the Work section with real client projects when available.
- Update hello@coderooters.com in index.html to your real business email before launch.
- Add your real social links/contact details if you want them displayed.
- Google Fonts are loaded online; the site still works if they are unavailable, using fallback fonts.

This is a static front-end portfolio. The contact CTA opens the visitor's email application; it does not submit to a server. For a working enquiry form, connect a backend or form service.
